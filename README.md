# Сравнение солнечно-дизельных станций

Расчёт почасового баланса для туристического объекта по погодным рядам PVGIS за 2005–2023 годы. Проверяются юг России, Алтай и Карелия. Нагрузка и цены заданы как условия примера. В расширенном эксперименте рассчитан 24 021 сезонный вариант; сводки и результаты отложенной проверки лежат в `model/experiment2`.

Для проверки сохранённых таблиц нужен Python 3.12. Выполните из корня:
```sh
python prepare_inputs.py --tables
python model/verify_results.py
python model/verify_experiment2.py
```

Для полного пересчёта сначала загрузите три погодных ряда с сервера Европейской комиссии (JRC PVGIS):
```sh
python prepare_inputs.py --weather
python model/calculate.py
python model/experiment2.py
```

Адреса, периоды и SHA-256 исходных файлов указаны в `issledovanie-data/weather-manifest.json`. Расчёт проверяет точное совпадение исходных данных. Если поставщик изменит ответ, нужен снимок с указанной контрольной суммой. Варианты сравниваются в рамках одной модели и одних исходных цен; результаты не заменяют проектирование конкретной станции.
